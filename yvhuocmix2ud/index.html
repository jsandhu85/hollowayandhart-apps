                                      Help

                                      Where your data is kept

                                      Everything you type stays in this browser on this device. Nothing is sent anywhere, and the app works with no internet. There is no account and no subscription.

                                      Keep a backup

                                      Settings → Back up now saves a small .json file. Do it every few weeks. The app reminds you if it has been 30 days.

                                      If you clear your browser's history or site data, the app's data goes with it. A backup brings it back: Settings → Restore a backup.

                                      Open it the same way each time

                                      Each browser keeps its own copy. If you open the app in two different browsers, you get two separate copies. Pick one way to open it and stay with it. Restore your backup if it ever opens empty.

                                      A new phone or computer

                                      On the old device: Settings → Back up now. Move the backup file to the new device, open the app there, then Settings → Restore a backup.

                                      Logging a workout

                                      Start a routine or a free workout. Each set has a weight box, a reps box and a tick. Tick a set when it's done: if the reps box is empty it takes the reps you're aiming for. Beside each set is what you did in the same set last time. Only ticked sets are saved when you finish.

                                      Did a session earlier? Change the date at the top of the workout before you finish it.

                                      The suggestion

                                      It looks at the last time you did the exercise. If you did every set at your target reps, it suggests one step heavier (the step in Settings, or the exercise's own step) or one more rep. If not, it suggests staying at that weight until you do. It is only a suggestion: go by how the session feels.

                                      How the numbers are worked out

                                      Volume = weight × reps, added up over every ticked set. A bodyweight set with no weight adds 0.

                                      Estimated 1RM (the most you might lift once) uses the Epley formula: weight × (1 + reps ÷ 30), rounded to the nearest 0.5 kg or 1 lb. A single rep is the weight itself. It is an estimate, and closest for sets of about 10 reps or fewer.

                                      Bests are your heaviest weight, best estimated 1RM and most reps at each weight, each with the date you first reached it. The first time you log an exercise, its top set is its first record.

                                      Body changes compare each measurement with its previous entry.

                                      Weeks start on the day in Settings.

                                      The rest timer

                                      It keeps time from the moment you press Start, so it stays right if you switch apps and come back. It only runs while this page is open. The sound is off unless you turn it on in Settings.

                                      This app is a log for your own training. It isn't medical advice.
