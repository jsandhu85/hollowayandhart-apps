                          Help

                          Where your entries are kept

                          Everything you type stays in this browser on this device. Nothing is sent anywhere, and the app works with no internet. There is no account and no subscription.

                          Keep a backup

                          Settings → Back up now saves a small .json file to your downloads. Do it every few weeks. The app reminds you if it has been 30 days.

                          If you clear your browser's history or site data, the app's entries go with it. A backup brings them back: Settings → Restore a backup.

                          Open it the same way each time

                          Each browser keeps its own copy. If you open the app in two different browsers, you get two separate copies. Pick one browser and keep the app file in one place: in some browsers a moved or renamed file opens empty. Restore your backup if that happens.

                          A new phone or computer

                          On the old device: Settings → Back up now. Copy the app file and the backup file to the new device, open the app there, then Settings → Restore a backup.

                          How the days work

                          Today has three slots and an Also list. Whatever isn't ticked by the end of the day comes along to the next day, marked 'from yesterday'. Nothing is lost and nothing nags.

                          Routines reset their ticks each day. Habit streaks count the days in a row up to today, or up to yesterday if today isn't ticked yet. You can tick yesterday late, but not earlier days.

                          The focus timer keeps time from the moment you pressed Start, so it stays right if you switch tabs. It only runs while this page is open.

                          This is a planner with an ADHD-friendly layout: few inputs, big text, calm words. It isn't health advice.
