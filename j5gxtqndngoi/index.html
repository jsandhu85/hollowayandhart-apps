      Help

      Where your list is kept

      Everything you type stays in this browser on this device. Nothing is sent anywhere, and the app works with no internet. There is no account and no subscription.

      Keep a backup

      Settings → Back up now saves a small .json file to your downloads. Do it every few weeks. The app reminds you if it has been 30 days.

      If you clear your browser's history or site data, the app's list goes with it. A backup brings it back: Settings → Restore a backup.

      Open it the same way each time

      Each browser keeps its own copy. If you open the app in two different browsers, you get two separate lists. Pick one browser and keep the app file in one place: in some browsers a moved or renamed file opens empty. Restore your backup if that happens.

      A new phone or computer

      On the old device: Settings → Back up now. Copy the app file and the backup file to the new device, open the app there, then Settings → Restore a backup.

      How the numbers work

      Spent adds up the price of every gift that is Bought, Wrapped or Given. An Idea's price is planned, not spent. Left to spend is your total budget minus spent: everyone's budgets added up, or the one overall budget you set in Settings.
